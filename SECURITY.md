# Security policy

## Supported versions

`op_infer` has no released or production-supported version. The public `main`
branch is pre-alpha source with publication explicitly disabled.

## Reporting a vulnerability

Report a suspected vulnerability through
[GitHub private vulnerability reporting](https://github.com/ACCIDDA/op_infer/security/advisories/new).
Do not open a public issue for a suspected security defect.

Include the affected commit, component, environment, reproduction steps, and
expected impact. Do not include credentials, confidential data, or other
secrets. Maintainers will coordinate disclosure and remediation through the
private advisory.

Ordinary statistical, numerical, and modeling correctness questions without a
security impact belong in the public issue tracker.
